# SkillBox Skill 操作与安装保护 v4

## 这次解决什么

- 每份 Skill 都能一键安装到本机全部可用应用。
- 每份 Skill 都能一键从所有应用卸载。
- 用户可以删除不再需要的 Skill，删除前会确认，内容保留在本机可恢复目录。
- “安装到哪里”更名为“自定义安装”，用于逐个微调安装位置。
- 未找到应用或正确 Skills 目录时，SkillBox 只提醒并跳过，绝不擅自创建目录。
- “查看技术信息”只展开轻量摘要，长篇原始说明按需打开，减少界面卡顿。

## 操作规则

### 安装到全部可用应用

1. 只选择已检测到正确目录且可以写入的应用。
2. 确认框列出即将安装和被跳过的应用。
3. 用户继续后仍进入安装清单预览，最后确认才复制文件。
4. 扫描、预览和真正执行三层都会检查目录，避免目录在操作中途消失后被重新创建。

### 从所有应用卸载

1. 只移除由 SkillBox 安装并仍符合记录的副本。
2. 外部修改或非 SkillBox 管理的同名目录会停止操作并解释原因。
3. 用户先查看卸载清单，确认后才执行。

### 删除这份 Skill

1. 如果还有 SkillBox 管理的安装副本，先引导“从所有应用卸载”。
2. 没有安装副本时再显示单独的删除确认。
3. 删除不会直接抹掉内容，原件移入 SkillBox 的 `Deleted` 目录以便恢复。

## 性能处理

原来的技术信息会在主界面同步读取并排版整份 `SKILL.md`。较长说明在展开时会占用界面线程。v4 将文件读取放到后台，并用系统原生文本视图在独立窗口中按需显示；主详情页只保留内容校验码与打开入口。
