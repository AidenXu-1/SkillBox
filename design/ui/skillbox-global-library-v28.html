给一个全新软件项目建好开工前需要的基础文件：项目说明、AI 协作规则、基础目录和 Git 备份。完成后就能接着写需求和开发。

你准备从零做一个 App、网站或其他软件，而且以后会持续更新它。项目还没正式开始、目标文件夹是空的时候用。

一套可直接开工的项目结构、开发规则、关键说明文档，以及后续 AI 都能读懂的协作入口。

1

它先确认项目名和一句话介绍；你还没想清楚时，会原样记下，不会替你编需求。

2

它检查目标文件夹是否为空。里面已经有文件时会停下询问，避免覆盖现有项目。

3

确认后，它创建项目说明、AI 协作规则、基础目录和第一次 Git 备份，然后告诉你下一步该写需求了。
