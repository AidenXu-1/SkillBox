# SkillBox Skill 详情布局 v5

## 设计判断

旧版把标题、来源、文件数量、三个管理动作、安全说明和技术信息连续堆在右侧面板里。所有内容几乎同权重，用户很难一眼判断先看什么、先点什么。

v5 按消费级产品常见的阅读顺序重排为四层：

1. **身份信息**：图标、名称、用途、来源、文件数量和更新时间。
2. **主要动作**：全部安装与全部卸载放进一张明确的任务卡；删除保留在卡片底部，降低误触与视觉干扰。
3. **当前状态**：已安装应用和使用前检查分别呈现，不再和操作按钮挤在一起。
4. **内容详情**：「查看技术信息」改为「查看 Skill 详情」，承载完整目录、主 `SKILL.md` 预览入口和内容校验码。

## 目录与预览规则

- 目录在后台读取，展开详情时不阻塞主界面。
- 展示 Skill 中的全部文件和文件夹，保留真实层级与文件大小。
- 软链接只显示，不沿链接继续读取 Skill 目录之外的内容。
- `SKILL.md` 在目录中高亮，并在详情顶部提供独立「预览」按钮。
- Markdown 预览为只读独立窗口，避免长文档重新挤压主详情页面。

## 视觉原则

- 主操作使用克制的蓝色浅底卡片，安全通过使用低饱和绿色状态卡。
- 目录使用接近 Finder 的文件图标、缩进和固定高度滚动区域，降低学习成本。
- 危险操作使用文字型红色按钮，保持可发现，但不和安装主按钮竞争注意力。
- 所有展开和弹窗均可立即响应，并支持减少动态效果偏好。

## 验收记录

- 可操作原型已验证：详情展开/收起、完整目录显示、Markdown 预览打开/关闭均通过。
- Swift 核心增加目录读取测试，验证完整层级和软链接不跟随。
- 真实 Agent 目录未参与本轮验证，也未被修改。
