隐私与安全

用普通话说明 SkillBox 会读取什么、什么时候联网、哪些事绝不会偷偷做。

安全边界
✓查看 Skill 时不会运行里面的文件

SkillBox 只读取文件结构和文字说明，不执行脚本、安装依赖或启动程序。

✓已有文件不会被悄悄替换

安装和更新前先展示清单，内容被其他软件改过时会停下来提醒你。

✓只有你主动操作时才发送内容

添加 GitHub 来源、检查更新、寻找 Skill 或获取 AI 介绍时才联网。

✓API Key 只保存在 Mac 钥匙串

不会进入设置文件、日志、操作记录或 AI 请求预览。
