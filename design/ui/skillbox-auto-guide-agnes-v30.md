# SkillBox v30：Agnes 自动补齐 Skill 介绍

## 产品结论

Skill 介绍改为 SkillBox 的内置基础能力，由 Agnes 默认整理。用户只在第一次使用时确认一次数据去向；同意后，现有及以后新增或变化的本机、私人 Skill 都自动补齐，不再逐个询问，也不要求普通用户填写 API Key。

## 首次授权

- 明确说明接收方是 Agnes 2.5 Flash。
- 明确说明发送内容：`SKILL.md`、`README`、作者文字说明，以及经过脱敏的 Skill 名称和描述。
- 明确说明不会发送：可执行脚本、二进制、图片、密钥、完整文件夹；不会运行 Skill 内容。
- 主操作为「同意并开始整理」，点击后立即进入整理状态。
- 用户可以选择「暂不使用」，以后从「设置 → Skill 介绍服务」开启。

### 2026-09-02 精简

根据真实视觉反馈，首次版本的说明卡、两组数据卡和撤回段落同时出现，信息重复且文字密度过高。当前版本只保留一行结果、一行发送范围、一行不发送范围和两个选择按钮；撤回入口压缩为一句次要说明。

第二轮反馈指出「会发送／不发送」两行搭配勾选图标和卡片边界，很像可勾选项目。当前改为单条中性信息说明，不再使用选择控件的视觉语言。

## 后续体验

- 已授权用户打开「我的 Skills」时不再看到授权卡。
- 本机 Skill 尚无介绍时，原位置显示整理中状态；用户可以继续使用其他功能。
- 生成完成后原地替换为完整的作用、适用场景、最终结果、使用流程和启动提示词。
- Agnes 暂时不可用时保留已有介绍，不静默切换到 DeepSeek 或其他接收方。
- 用户关闭服务后停止发送新的说明文字，本机已有介绍继续保留。

## 技术与成本边界

- 视觉预览不调用任何真实 API。
- 正式“免填 Key”体验需要 SkillBox 服务端保存 Agnes 凭据，并承担鉴权、限流、缓存、防滥用、数据保留和隐私合同。
- Agnes 免费额度属于当前外部条件，不能写成永久免费承诺；客户端不得内置共享 Agnes API Key。
