# 文件夹整理交互方向

保留现有三栏与蓝色选中样式，优化 Skill 与文件夹的直接拖动。

- Skill 行整体可抓取，同组或跨组排序用插入线说明位置；文件夹标题中部承接归类。
- 文件夹排序支持放在其他文件夹前后，包括末尾；固定“未分类”不参与文件夹排序。
- 悬停折叠文件夹约 650 ms 展开，列表边缘随拖动滚动，Esc 或离开列表后松手取消。
- 默认保留手动顺序。名称排序、搜索状态下明确暂停拖动，避免落下后被自动排序推走。
- 原生实现需统一手势与落点处理，移动行跟手，周围行平滑让位；放下后只保存整理元数据，不重新读取每份安装内容。
- 预览是浏览器模拟数据，尚不能代表原生 macOS 拖动性能；原生实现前需要确认交互方向，之后用真实长列表和跨文件夹拖动验收。

可操作文件：[preview.html](preview.html)。当前未提供 callable OpenDesign 工具，使用本地 HTML 兜底，不引入安装依赖。后续若启用 OpenDesign，可把已确认方向转为可编辑设计稿。

参考：[Apple 拖放指南](https://developer.apple.com/design/human-interface-guidelines/drag-and-drop)、[备忘录文件夹整理](https://support.apple.com/en-ie/guide/notes/apd558a85438/mac)。参考其直接操作与明确落点行为，不改变产品已认可的信息结构。
