# SkillBox 设置页 v31

## 设计目标

设置页只回答五个具体问题：AI 怎么连接、GitHub 怎么连接、数据放在哪里、如何恢复操作、SkillBox 的隐私和安全边界是什么。

## 信息架构

- **AI 服务**：先展示“Skill 介绍”和“发现 Skills”分别使用什么，再管理每家服务商的连接。
- **GitHub**：展示是否连接、可以访问哪些仓库，以及断开或清除信息的出口。
- **存储与记录**：合并保存位置、寻找记录、空间占用和清理动作，删除含糊的“数据”。
- **操作记录与恢复**：沿用既有恢复能力，但放进同一套设置页面层级，不再切换到视觉完全不同的独立页面。
- **隐私与安全**：合并原“安全承诺”、联网边界和钥匙串说明，删除内容稀薄的“通用”。

## 布局决定

1. 保留 SkillBox 一级导航，设置内容改成 macOS 熟悉的双栏结构。
2. 设置目录每行显示图标、明确名称和当前状态，避免顶部五个等权分段按钮。
3. 右侧统一使用“页面标题 → 分组标题 → 白色设置卡”的层级。
4. 普通状态用短文本和状态胶囊；解释放在受影响的控制附近。
5. 删除危险动作放在相关页面底部，不建立集中“危险区”。
6. 页面没有统计看板和装饰性大数字，空间只用于设置状态和动作。

## 交互

- 设置目录整行可点击，按下立即反馈。
- 切换页面使用短交叉淡化，不滑动整个页面；开启“减少动态效果”时直接切换。
- “连接”“管理”“恢复”等动作从当前行原地进入，不让用户跳到无关页面。
- 长路径单行截断，点击“在 Finder 中显示”承担定位任务。

## 正式实现

用户于 2026-09-02 确认本母版后，正式 SwiftUI 已按这套信息架构完成替换。AI 服务列表使用中性的 macOS 系统功能图标，不再用首字母伪装品牌图标；Agent 产品列表原有的可追溯官方图标不受影响。
