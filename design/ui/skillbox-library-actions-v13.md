# SkillBox 操作层级 v13

针对「我的 Skills」页的顶部操作和全局安装卡片做局部收敛。

## 顶部操作

- 「添加 Skill」是这个页面最高频的创建动作，使用唯一的蓝色主按钮。
- 「检查更新」和「连接私人仓库」使用统一高度的次要按钮。
- 三个控件保留 10 pt 间距，不再出现两个胶囊和一个裸文字菜单混用的状态。
- 文案缩短为「检查更新」，「全部」由页面语境表达。

## 安装卡片

- 说明和按钮拆成上下两层，不再把长文字和多个按钮挤在同一行。
- 直接告诉用户「已找到 5 个可安装应用」，并保留安装前查看清单的承诺。
- 主按钮改为「安装到全部应用」，固定单行显示。
- 「卸载全部」保留可见，但使用次要样式；「删除这份 Skill」留在卡片底部，避免和安装动作混在一起。
