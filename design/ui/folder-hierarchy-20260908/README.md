# 文件夹视觉层级调整

用户已认可当前拖动手感，本轮只处理文件夹相对单个 Skill 太小、分组层级不清的问题。

## 视觉候选

- 文件夹标题由 32 pt 提高至 54 pt，名称使用约 15 pt 半粗体；蓝色文件夹图标约 23 pt，带低对比底托。
- 标题使用浅灰蓝底色和细边框，数量用小型中性底色标签；选中的 Skill 仍用蓝色高亮，避免把文件夹背景误当选中状态。
- 内部 Skill 保持 44 pt 行高，向右缩进 24 pt。未分类保留为轻量分段标题，处于所有文件夹之后。
- 预览提供原来 / 调整后切换、折叠和拖动示意；只使用模拟资料，不能代替原生手感验收。

## 实施约束

用户确认视觉后再应用到正式界面。行高必须由显示与拖动几何共用，避免标题变大后落点偏移；文件夹浮动标题使用同样尺寸与字重。沿用原拖动阈值、跟手和让位动画、边缘滚动、悬停展开与保存逻辑。只修改列表表现，不改分类记录、安装逻辑和 Skill 内容。
