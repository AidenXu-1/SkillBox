# SkillBox 全局 Skill 管理 v28

## 设计目标

把产品收口为“从一个明确来源，把同一份全局 Skill 安装到多个 Agent”。删除总览看板、冲突中心和应用导入来源；保留真正有批量管理价值的安装关系表。

## 页面结构

- 一级导航按任务优先级排列为“我的 Skills、安装到应用、发现 Skills、设置”。前两个是管理已有 Skill 的核心任务；后两个与核心任务留出轻微间距。
- 侧边栏使用一个完整的导航容器，四个入口都是 46 pt 高的整行热区；非当前项也保留浅底色、边界和悬停反馈，不再像四行漂在背景上的文字。顶部用品牌区说清产品定位，底部用范围卡说清只管理全局 Skill，中间留白成为有意的层级。
- “最近操作”不占一级导航。每次安装、更新、卸载或删除完成后，就地告诉用户结果并提供即时撤销；更早的记录统一从“设置 → 操作记录与恢复”进入。这里只调整入口层级，不删除记录、备份或恢复能力。
- 应用打开后直接进入“我的 Skills”。
- 中栏是全局 Skill 列表，每行保留醒目的本地文件夹或 GitHub 来源图标，并显示安装结果；搜索、来源、安装状态和用户文件夹共同构成筛选。
- 右栏围绕选中的 Skill 展示来源、版本、已安装应用、AI 整理的介绍与文件结构。
- 单个 Skill 可以安装到全部应用、从全部应用卸载，也可以打开“管理安装”逐个选择。
- “安装到应用”作为批量工作区保留。Skill 列标题本身就是分类选择器，可选择全部、任一真实文件夹或未分类；Agent 列支持拖动排序并持久保存。
- 安装单元格只放醒目图标，状态图例只在表格上方出现一次：安装、已安装、可更新、已有同名、应用不可用。每个 Agent 只检查自己的标准 Skill 目录，不扫描 `.agents` 等共用目录，也没有“已可用、间接可用、间接可见”。
- Agent 列头使用官方产品图标、产品名称和本机目录状态；图标与名称共同建立识别，不能只放一排文字。原型图标全部来自官方品牌资源包、官网或本机已安装的官方 App，来源记录见 `assets/agent-icons/README.md`。
- 默认应用顺序调整为 GPT、Claude、WorkBuddy、ZCode、Kimi Code、Cursor、HanaAgent、Pi、DeepSeek Harness、Trae。用户可以拖动改顺序，也可以在“管理应用”中移出或加回某一列。
- GPT 只改变界面名称和图标，底层继续使用稳定的 `codex` 适配器及 `~/.codex/skills`，旧安装关系不会被当成另一款应用。Kimi Code 改用官方当前目录 `~/.kimi-code/skills`。

## 管理应用

- “管理应用”展示当前安装表中的应用、自己的全局 Skills 文件夹和检测结果。用户可把不使用的内置应用移出列表，随后也能加回来；自定义应用使用“删除”，只删除 SkillBox 中的目标记录。
- 被移出的默认应用既可逐个“加回来”，也可点击「恢复全部预设应用」一次找回。该动作不改变自定义应用、安装关系和已有列顺序；找回的列追加到末尾。
- 安装表里的排序操作明确命名为「恢复默认顺序」，只恢复十个预设应用的默认相对顺序，不承担找回应用，避免两个“恢复”动作互相冒充。
- 移出列表只改变 SkillBox 的展示与管理范围，不删除电脑上的应用、目录或文件。
- 某应用仍有 SkillBox 管理的副本时，正式实现必须让用户明确选择先卸载，或保留文件并停止管理；两种结果不能藏在同一个“删除”动作里。
- 列表里没有的产品通过“添加自定义应用”加入。用户填写产品名称并选择一个已经存在的全局 Skills 文件夹；SkillBox 不猜目录、不代建目录，也不把该目录里的内容导入“我的 Skills”。

## AI 整理的 Skill 介绍

- 「作用」：直接说它会替用户做哪件事、最后交付什么，不写「帮你想清楚」「不容易变乱」这类空泛效果。
- 「适用场景」：写清用户在什么时候应该启动它，用 App、网站、空项目文件夹等具体例子帮助判断。
- 用户视角的使用流程：写清 Skill 会先问什么、用户选择后会发生什么，或一步完成后会得到什么。
- 一条简短启动提示词，支持一键复制。
- 「Skill 介绍」与「文件详情」各占一半宽度，整块 46 pt 高的页签都可点，文字只负责命名，不再是唯一热区。
- 文件结构独立放在“文件详情”，不和用户说明混在一起。

## 添加合同

“添加全局 Skill”只允许两种选择：本地开发文件夹或 GitHub 仓库。发现页加入候选时复用 GitHub 来源流程。

## 实现边界

这是用户确认前的交互原型。正式 SwiftUI 页面尚未替换；历史 v27 原型保留为被否决的设计记录，不作为实现基线。
