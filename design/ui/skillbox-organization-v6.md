# Skill 分类与交互反馈 v6

## 目标

让 Skill 数量变多后仍然容易整理，同时让每个可点击位置在鼠标经过时给出明确反馈。

## 分类整理

- 「我的 Skills」左栏增加“我的分类”和“未分类”。
- 用户可以新建、重命名和删除分类文件夹。
- Skill 可拖入文件夹、拖回“未分类”，也可拖到另一个 Skill 前面调整同组顺序。
- 文件夹本身可以拖动排序。
- 右键菜单提供“移动到”，照顾不方便拖拽的用户。

分类只改变 SkillBox 中的列表组织方式。它不会移动、改名或删除中央原件，也不会改变任何 Agent 的安装状态。删除文件夹时，其中的 Skills 会回到“未分类”。

## 鼠标反馈

- 主要、次要和危险操作均有悬停、按下和禁用状态。
- 悬停采用轻微变色与描边，按下采用短促缩放，避免界面跳动。
- 系统开启“减少动态效果”时取消缩放动画，只保留颜色反馈。
- 「查看 Skill 详情」整行可点击，鼠标经过整行显示浅蓝背景；箭头旋转帮助识别展开状态。
