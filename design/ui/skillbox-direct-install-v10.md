# SkillBox 单项安装与使用流程 v10

- 安装矩阵取消右上角的二次执行入口。点击任何一个交叉点，当场展示并确认这一项操作。
- 应用内已有未管理的同名 Skill 时，点击前就显示橙色叠层图标；点击后告知两份内容相同或不同，并给出文件变化。
- 单项确认只执行当前 Skill 与当前应用，不会夹带其他待处理项。
- 「这个 Skill 怎么用」只从 `SKILL.md` 或 Skill 目录内 `README.md` 的明确流程章节提取，不猜测、不使用 AI；没有可靠步骤时不显示该卡片。
- 文件检查改为默认收起的二级信息，保留安全证据，不再抢占使用流程的视觉主位。
