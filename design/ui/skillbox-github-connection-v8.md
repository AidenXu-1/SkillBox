# 私人仓库连接 v8

## 设计目标

- 用户只看到“连接私人仓库”，不需要理解底层授权技术。
- 在点击前明确三步流程，并说明无需下载其他软件。
- 公开仓库仍可直接添加，私人仓库只读取用户选择的范围。
- 连接后将“管理可访问仓库”“断开连接”“清除 GitHub 信息”“在 GitHub 撤销授权”分开表达。

## 数据边界

- 断开连接：清除本机钥匙串登录信息，保留仓库跟踪选择；公开仓库仍可正常检查，私人仓库下次检查时提示重新连接。
- 清除 GitHub 信息：进一步移除仓库地址和更新记录，Skill 内容保留为本地副本。
- GitHub 端撤销授权：打开 GitHub 官方设置页，由用户亲自确认。
