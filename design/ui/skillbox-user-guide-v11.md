# SkillBox 用户使用指南 v11

「这个 Skill 怎么用」改为面向普通用户的渐进式说明：

- 始终优先回答「能帮你什么」。
- 作者有提供时，再补充「什么时候适合」和「可以这样告诉 AI」，示例话术可一键复制。
- 只有作者明确写了用户会经历什么，才显示最多三步的使用体验。
- 不再把 Skill 内部的「执行步骤」「安全检查」等 Agent 指令当成用户教程。
- 信息不完整时自动省略缺失区块，至少保留一句确定的用途，不使用 AI 猜测。

预览：

- `skillbox-user-guide-v11-complete.png`：用虚构 Skill 展示作者资料完整时的界面，不代表对某个现有 Skill 的自动推断。
- `skillbox-user-guide-v11-basic.png`：只能确定 Skill 用途时的简化界面。
