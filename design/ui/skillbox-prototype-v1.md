# SkillBox 交互原型 v1

## 设计目标

让一个不熟悉隐藏目录的用户，在第一次打开应用时就获得三种感受：

1. **安全**：盘点只读，写入前必有预览，写入后可以撤销。
2. **清楚**：主流程使用日常语言，技术信息收进可展开的第二层。
3. **有掌控感**：用户决定添加哪份内容、安装到哪些应用、何时真正开始。

## 信息架构

- **总览**：已加入数量、本机找到数量、需要选择的内容和应用位置。
- **我的 Skills**：集中保存的 Skill 列表与使用前检查。
- **安装到哪里**：选择哪份 Skill 安装到哪个应用。
- **最近操作**：备份、安装结果和“恢复到操作前”入口。
- **设置**：数据与隐私、安全承诺和保存位置。

## 关键交互

- 首次打开先解释只读边界，再开始扫描；扫描完成不自动同步。
- 安装矩阵点击后只改变“计划”，顶部按钮即时显示待同步数量。
- 同步预览将新增、更新、移除和阻塞分组；阻塞项不能随确认操作执行。
- 同步完成后使用窗口底部的非阻塞通知提供“查看记录”和“撤销”。
- Kimi Code 的间接加载用带说明的链路状态表示，避免误导为直接安装。

## 视觉语言

- 使用系统字体、macOS 三栏空间关系、克制的蓝色主操作和绿色健康状态。
- 背景与卡片主要靠明度和轻边框分层，减少玻璃叠加。
- 警告使用暖橙，危险使用红色，但只在确有用户动作时出现。
- 常用文字不低于 13px；状态不只依赖颜色，同时配合图标与标签。
- 支持减少动态效果、减少透明度和增强对比度偏好。

## 原型操作说明

- 点击左侧导航切换五个主要页面。
- 在 Skill 库点击列表项查看不同原件。
- 在 Agents 矩阵点击圆形安装按钮，再打开“预览同步”。
- 点击“同步 4 项变更”可体验同步完成与撤销提示。
- 点击左下角“重新体验首次盘点”打开首次引导。
