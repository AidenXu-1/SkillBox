# SkillBox v29：本机 Skill 介绍授权态

## 这次解决什么

本机 Skill 缺少完整介绍的真实原因，是默认隐私保护不允许把本机或私人 Skill 的说明文字发给 AI。当前界面只显示能从作者原文确定的简要内容，却没有告诉用户其余内容为什么没出现。

## 设计决定

- 不在后台偷偷打开隐私权限。
- 不让用户离开当前 Skill，再去设置里寻找一个不理解的开关。
- 在缺少内容的位置直接解释原因，并明确写清会发送与不会发送的内容。
- 授权按钮写成「允许并整理」，点击后先显示正在整理，再在原位置补全「适用场景、结果、使用流程、启动提示词」。
- 授权范围与现有数据模型保持一致：授权给当前 AI 配置，用于之后打开的本机和私人 Skill；更换服务商、模型或接口后重新确认。

## 交互

- 「先看文件详情」直接切换到文件页，用户不必授权也能继续查看和管理 Skill。
- 「允许并整理」是唯一会改变隐私授权状态的主操作。
- 预览中的按钮只演示状态变化，不会真的把任何本机文件发送给 AI。
