# 更新内容对比方案

依据用户2026-09-20截图和要求提出的设计预览，尚未修改产品代码。

- 保持左右两个连续文本窗口，不使用逐行格子、不为了逐行对齐插入空白占位。旧版删除或被替换的行使用删除线，新版新增或修改行使用浅黄色背景；未改动部分正常显示。按行比较，首期聚焦SKILL.md，避免整篇改色。
- 两入口共用对比内容组件，数据独立：我的Skills比较中央保存版本与来源新版本；安装确认比较目标应用现有文件与准备安装的中央版本。后者不是额外去来源拉新版。
- 安装确认弹窗右上角增加“查看更新”。由当前确认弹窗打开只读详细页，右上关闭或Esc只关闭详细页，保留确认弹窗与原操作。详情不重复放替换按钮。原我的Skills更新页仍保留它原来的确认更新操作区。
- 图二实际是已有同名Skill的替换确认；详细入口应同时覆盖正常更新与同名替换，不将两种情况混用。
- 旧版文字删除线是原生文本可以表达的样式；主要工作在识别变化及正确接入两组内容。初期按行标记，不承诺逐字对齐。处理仅新增、仅删除、修改、完全相同，以及长文、中文换行。
- 此HTML为样例内容与交互示意，不展示实际Skill内容、不执行真实更新。顶部可以切换两入口，第二入口查看后关闭应保留确认层。
