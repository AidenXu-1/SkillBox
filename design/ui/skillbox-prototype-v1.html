# WeChat Layout Publisher

用于把已经确认的文章整理成可复制、可发布、可归档的公众号版本。

## 工作步骤

1. 检查文章内容与配图计划
2. 生成适合公众号的 HTML 排版
3. 用户确认后创建草稿
4. 发布后保存归档记录
新建文件夹

文件夹只用于整理列表，不会移动或修改 Skill 原件。
