# SkillBox 设置页 v18

## 目标

- 总览只看状态与待处理事项，Skill 搜索只在「发现 Skills」完成。
- 设置页从一张超长表单改为「通用、AI、GitHub、数据」四个稳定入口。
- 首层只显示用户能够理解、确实会调整的功能；技术字段、危险操作和长列表进入第二层。

## 页面职责

- 通用：保存位置和欢迎说明。只陈列但无法操作的“使用数据”不再占用页面。
- AI：开关、默认模型、六类服务接入、连接测试、密钥管理和允许发送的内容范围。
- GitHub：私人仓库连接状态、连接入口、连接后的能力和收起的连接管理。
- 数据：寻找记录、保存目录和清理入口。

## 交互原则

- 页面顶部切换分类，不再要求用户在一张长页面里寻找。
- 公开 GitHub 无需登录的信息始终直接显示，私人仓库连接才出现主按钮。
- AI 服务以 Agnes、DeepSeek、Kimi、MiniMax、GLM、自定义 API 六张卡片呈现。点击服务后，就地填写 API Key、选择模型并“保存并测试”，不再跳进含糊的“管理连接”。
- 内置服务的接口地址由 SkillBox 预填；只有自定义 API 需要用户填写接口地址和模型 ID。
- 每家服务的 API Key 独立保存在 macOS 钥匙串，删除一家的密钥不会影响其他服务。
- 危险操作保持可找到，但不与日常设置并列竞争注意力。
