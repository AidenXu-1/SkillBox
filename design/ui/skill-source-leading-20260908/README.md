# Skill 左侧显示来源图标

沿用用户已确认的文件夹层级：54 pt 标题、加大图标、内部 Skill 缩进。

- Skill 左侧使用现有来源标识，替代无额外辨识信息的首字母；本地为蓝色文件夹，GitHub 使用现有章鱼猫图标。
- 图标约 22 pt，保持 26 pt 容器，不增加行高。移除右侧重复来源标识，保留固定宽度的大小信息，为名称释放空间。
- 归类文件夹使用较大的有底托标题，Skill 来源图标不加底托，结合子级缩进区分两种文件夹图标的作用。图标保留来源悬停说明和无障碍名称。
- 只调整“我的 Skills”列表，不扩展到详情头像或发现页面。

[可操作预览](preview.html)，可切换首字母与来源图标。当前没有 callable OpenDesign，沿用已获认可的本地 HTML 流程。此来源图标方案待视觉确认，文件夹层级已确认可实施。
