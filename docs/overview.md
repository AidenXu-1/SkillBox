# 项目总览

## 一句话定义

SkillBox 是面向 AI 产品创作者的开源 macOS 应用，用一座本地中央仓库管理 Skills，并安全分发到多个 Agent。

## 要解决的问题

多个 Agent 各自维护 Skills 目录，用户难以判断原件、重复、冲突、实际加载状态和一次同步会改动什么。

## 核心价值

- **看清**：统一资产视图和真实安装状态。
- **收拢**：中央仓库保留可信原件和来源。
- **安全**：只读盘点、风险报告、变更预览和所有权边界。
- **可恢复**：事务备份、失败恢复和撤销。

## 产品边界

第一版只做 macOS 全局 Skills 治理，不扩展到市场、编辑器、团队云端或跨平台。

## 成功标准

不熟悉隐藏目录的用户，也能在不损坏现有环境的前提下完成一次盘点、归并、分发和撤销。
