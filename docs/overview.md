# 项目总览

## 一句话定义

SkillBox 是面向 AI 产品创作者的开源 macOS 应用，统一管理跨项目使用的全局 Skills，并一次安装到多个 Agent。

## 要解决的问题

多个 Agent 各自维护全局 Skills 目录，普通用户不熟悉隐藏路径，同一份 Skill 需要重复安装、更新和卸载。

## 核心价值

- **一个来源**：每份 Skill 只关联本地开发文件夹或 GitHub。
- **统一安装**：选择一次，就能安装到多个 Agent。
- **安全**：只读来源、风险报告、变更预览和所有权边界。
- **可恢复**：事务备份、失败恢复和撤销。

## 产品边界

第一版只做 macOS 全局 Skills 管理。项目级 Skill 完全不扫描、不导入、不展示，也不扩展到编辑器、团队云端或跨平台。

## 成功标准

不熟悉隐藏目录的用户，也能从本地开发文件夹或 GitHub 添加 Skill，安装到多个 Agent，并安全卸载或撤销。
