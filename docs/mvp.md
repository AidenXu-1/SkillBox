# SkillBox v1 MVP

> 正式合同以 [spec.md](spec.md) 为准。

## 核心承诺

用户可以看清本机的 Skills，把可信版本收进中央仓库，预览后分发到多个 Agent，并在出错时恢复。

## 必须能完成的闭环

1. 首次只读扫描九个内置 Agent 和通用目录。
2. 归并相同副本，处理同名冲突并建立中央仓库。
3. 从本地目录或公开 GitHub 仓库新增 Skill，并看到本地风险报告。
4. 在安装矩阵选择目标 Agent，预览后同步。
5. 发现目标漂移、查看事务记录并安全撤销。

## 首版不承担

项目级安装、市场、私有仓库、编辑与创建、AI 审查、团队与云端、跨平台、自动同步和自动更新。

## 完成门槛

- [x] 核心闭环均有自动化测试和可恢复失败用例。
- [x] 真实环境只读扫描零改动。
- [ ] 可操作原型与正式应用均通过前台鼠标和键盘验收。
- [ ] ad-hoc Hardened Runtime 签名、发布包隐私扫描、SHA-256、干净账户“仍要打开”安装和 Release 下载校验全部独立通过。
