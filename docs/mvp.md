# SkillBox v1 MVP

> 正式合同以 [spec.md](spec.md) 为准。

## 核心承诺

用户可以从本地开发文件夹或 GitHub 添加一份全局 Skill，预览后安装到多个 Agent，并在出错时恢复。

## 必须能完成的闭环

1. 自动发现十个默认内置 Agent 的全局安装位置，不把其中的副本当成来源；老用户已有的其他内置目标继续兼容。
2. 从本地开发文件夹或 GitHub 添加 Skill，并看到可安装内容和本地风险报告。
3. 为每个 Skill 选择一个或多个 Agent，预览后统一安装。
4. 从同一来源检查更新，用户确认后更新所选 Agent。
5. 统一卸载、查看操作记录并安全撤销。

## 首版不承担

项目级 Skill、信息流市场、编辑与创建、团队与云端、跨平台、自动安装和自动更新。

## 完成门槛

- [x] 核心闭环均有自动化测试和可恢复失败用例。
- [ ] 真实环境只发现 Agent 全局安装位置，不读取项目级 Skill、不创建来源且零改动。
- [ ] 可操作原型与正式应用均通过前台鼠标和键盘验收。
- [ ] ad-hoc Hardened Runtime 签名、发布包隐私扫描、SHA-256、干净账户“仍要打开”安装和 Release 下载校验全部独立通过。
