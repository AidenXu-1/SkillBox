# ADR-0017：多平台反复推荐后再核验 Skill

- **状态**：已被 ADR-0018 修正运行边界
- **日期**：2026-09-04
- **扩展范围**：将 ADR-0016 中 Hacker News 单一社区线索扩展为中英文多平台证据；ADR-0015 的免费、GitHub 真文件核验、限流和存储边界继续有效。

## 背景

Hacker News 对开发者话题有价值，但它无法代表中文用户实际获取 Skill 推荐的地方。目标用户更常在 YouTube、B 站、抖音、小红书和公众号中搜“有没有好用的 Skill”。只看 HN 会产生一种虚假的精确：候选可以核验，却与用户真正看到的口碑圈脱节。

## 决定

1. 默认公开线索覆盖 YouTube、B 站、公众号和 Hacker News。小红书与抖音需要登录态，只在用户对当次寻找主动开启后读取已登录 Chrome 中公开可见的搜索结果，不后台监控，不关注、点赞、评论或发布。
2. 平台适配器只产出临时媒体线索：平台、帖子编号、作者、标题、公开链接、可比的单条互动数和必要的短摘要。视频、字幕、文章正文和网页不进入寻找记录。
3. 只从线索中提取可追溯的 GitHub 仓库身份或精确 Skill 名。每个名称必须绑定原始帖子证据；模型若参与提取，只能返回输入中原样存在的名称和证据编号，不得猜仓库。
4. 线索经 GitHub 搜索后，只有候选名称或仓库与线索精确对上，且当前真实 `SKILL.md` 核验通过，才能附加社区证据并进入候选。
5. 独立提及者按规范化作者身份去重；相同名号在多平台出现时也只计一人，拿不到作者身份的帖子只保留平台线索、不计入独立人数。排序先比较直接任务匹配，再比较独立提及者、跨平台覆盖和 Skill 级安装量。播放、点赞、评论因口径不同，不做跨平台绝对数相加。
6. 媒体路线是可失败的增强层。每个平台独立限时、限量和报错；可选工具缺失、登录失效、验证码或页面变化不得删除其他来源的已核验结果。

## 免费与工具边界

- 不购买搜索 API、社交媒体数据、代理池、Embedding、向量库或托管索引。
- YouTube 优先使用开源 `yt-dlp` 读取公开搜索结果；中文平台优先使用开源 OpenCLI 的只读适配器。两者均为可替换外部工具，缺失时必须降级，不得执行自动安装或自动修复。
- 只有用户已配置的 Agnes 免费方案或用户自备的模型 API 可能产生模型调用；其他搜索与存储不产生持续费用。
- 不采用 MediaCrawler：其当前仓库明确限定为学习用途并禁止商业使用，不适合作为 SkillBox 产品依赖。

## 存储边界

- SkillBox 不保存视频、字幕、文章正文、媒体搜索页、平台 Cookie 或公开网页镜像；寻找记录仍只保存每个候选最多 5 条证据元数据，并受现有 64 MiB 总上限约束。
- 只增加代码时，目标是应用包固定增量小于 1 MiB。
- 用户可选安装 OpenCLI 与 `yt-dlp` 时，npm 页面显示的 OpenCLI 包本体解包大小约 13.3 MiB，但当前 Mac 连同依赖、配置骨架和补全文件的真实落盘占用约 31.0 MiB；`yt-dlp` 约 35.4 MiB，合计实测约 66.4 MiB。已有 Node 运行时不重复计入。如未安装这两项，这部分新增为 0。
- 不使用需要额外下载约 150 MB 无头浏览器的小红书采集方案。

## 验收

- 同一作者在 YouTube 和 B 站重复发布的内容只计一位提及者；两位独立作者在不同平台提及同一 Skill 时，候选应显示两位提及者和两个平台。
- 媒体标题中的普通单词、未绑定证据的模型输出或无法在 GitHub 对上的名称不得形成候选。
- 任一平台超时、缺工具、需登录、出现验证码或返回损坏结构时，其他来源结果保留，完成度不得写成全部完成。
- 小红书与抖音在未得到当次用户允许时不发起请求；允许后也只运行搜索命令。

## 回退

多平台来源通过独立适配器和原有 `SkillDiscoveryProvider` 合并。移除外部平台适配器即可回到 HN、可信目录、skills.sh 和 GitHub 四路搜索；持久化字段只扩展平台枚举，旧寻找记录无需删除或重建。
