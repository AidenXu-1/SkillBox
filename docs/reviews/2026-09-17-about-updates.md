# 关于、应用内更新与删除提示验收

日期：2026-09-17。对应 Spec v2.61。版本0.2.5，构建18。

## 实现结果

设置增加“关于”：版本与复制、检查更新、默认自动检查、可选自动下载、仓库、作者主页、更新日志和反馈。采用已确认的原生三栏样式；批注要求删除的说明文字未进入产品。

删除提示6秒后隐藏，悬停、键盘焦点或窗口不活跃时暂停；启动不再重新显示旧提示。隐藏提示不删除恢复记录。操作记录支持纯中央删除的恢复，恢复后不再显示失效的恢复按钮，并正确区分“删除了”和“恢复了”。

Sparkle2.10.0负责签名校验、原路径替换和重启，不复制或改写 App 外资料。原有 Skill 文件操作恢复机制不变。发布工具增加签名更新ZIP及签名appcast；只生成本地文件，不自动发布。签名私钥在钥匙串，未导出、未提交。
