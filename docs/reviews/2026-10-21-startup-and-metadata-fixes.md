# SkillBox 本会话五项问题修复与验证

日期：2026-10-21。以本机与公开 3.0.2（31）为原有版本，在保留工作区已有差异、后台规划、文件安全与测试入口修复的基础上，补齐本会话五项问题。正常页面、技能内容、安装关系与恢复规则保持；没有打包、安装、替换 App 或发布。

后续已明确本组额外改动与原五项清单的交叉，并重新验证完整合并版本，见[合并版本完整复核](2026-10-21-combined-review.md)。以下保留本组修复时的记录。

## 修复范围

| 问题 | 当前实现与验证 |
|---|---|
| 更新清单遗漏 | 保留已完成的差异修复，覆盖隐藏配置、空目录、类型和权限；仅忽略普通 `.DS_Store`。`SkillDiffTests` 与实际替换预览相关回归通过。 |
| 技能名称读错 | `SkillMetadataParser` 只读取顶层名称和简介，保留缩进与折行说明。嵌套资料位于顶层字段之前或之后、缩进文档和真实导入均有回归；来源及保存副本字节保持。 |
| 刷新占用界面通道 | 保留已完成的后台规划与差异读取；复核取消、迟到结果、较新状态保护以及单项和批量操作。`BackgroundPlanningTests` 与安装响应回归通过。 |
| 启动失败直接退出 | `AppModel` 把准备失败交给启动协调器处理；不创建空白替代库、不终止进程。正常启动继续使用原有 `ContentView`。辅助目录就绪后才打开技能库，失败提示可重试和访达定位。搜索记录、介绍目录、中央库和根路径占位的回归均保护原文件，修复路径后能读取原技能与安装关系。 |
| 测试入口漏跑 | 保留已完成的参数化标识适配和零匹配失败检查；完整运行没有零匹配提示。Python 入口回归同时验证发现失败、执行失败及两种标识表示。 |

启动初始化现在显式返回错误；现有测试中相应的构造与样例辅助方法增加错误传递，原有业务断言未放宽。没有新增依赖或资料格式迁移，没有自动重命名已有安装目录。

## 验证结果

- 同一次完整运行实际通过 **654 项 Swift 检查**，**1 项原有公网检查按默认设置跳过**；**35 项 Python 检查通过**。655 为含跳过项的框架报告总数。
- 修复前，新增的名称读取与导入回归有 3 项失败；修复后对应扫描与名称专项 40 项通过。启动与名称合计 5 项正式回归通过，参数覆盖多个故障位置与重复重试。
- 从当前工程逐文件复制并校验的隔离副本完成完整测试和发布模式编译；结束后当前工程仍与测试清单一致。没有运行发行打包或安装脚本。
- 只读核对 **19 处中央技能目录及受管安装副本**，内容、类型、权限、链接、技能记录、安装选择、安装记录和分类保持原值；已安装 App 的整个目录核对保持原值。
- `ContentView.swift`、`AboutSettingsView.swift`、`SkillMarkdownComparison.swift`、`OrganizerDragLayout.swift` 与开始时逐字节一致。应用入口仅增加启动异常分支，正常页面、窗口尺寸和更新器接线保留。
- 最终代码复核覆盖名称字段的层级、构造错误传播、无替代库、重试恢复与重复启动、后台结果失效保护、测试筛选及实际运行数量。
