# 更新正文对比接入

## 已实现

- 我的 Skills 更新预览使用连续双栏原文：旧版变化行删除线，新版变化行浅黄色文字背景。没有表格行、补齐空行或横向滚动；保留自然换行、文本选择和独立滚动。
- 安装更新及不同内容的同名替换确认右上角增加“查看更新”。详情由当前确认窗口呈现，独立关闭，不调用安装操作或全局更新取消；保留原确认。正文方向为应用当前内容到中央我的 Skills 版本。
- 两个入口共用正文组件；安装详情保留完整文件变化列表，正文仅显示 SKILL.md。读取失败显示说明，不把错误文案当作正文比较。
- 无新增依赖。Swift 标准库按行计算，UTF-16 范围适配中文和表情，后台运算后更新原生文本。两侧共同前后文先排除，剩余行数乘积超过 400 万时标记整个变化区段并明确说明，避免密集改写产生过量计算。
