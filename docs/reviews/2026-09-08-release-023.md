# v0.2.3 发布候选

日期：2026-09-08。用户要求推进最新版本上线。候选版本 0.2.3 Build 7，基于已完成本机真实验收的 v2.54 产品实现；本次不改变 Skill 内容筛选、来源跟踪或安装保护规则。

## 发布内容

- 取消启动时对应用安装目录中未知 Skill 的递归发现；单项安装和卸载只核对当前目标，确认窗显示处理状态与错误。
- 优化文件夹与 Skill 的拖动、跨组移动和排序；文件夹置顶，未分类 Skill 位于所有文件夹之后。
- 加强文件夹视觉层级，归类采用收纳盒图标；Skill 左侧显示本地来源或 GitHub 标识。
- 修复发现对话的新查找识别、暂停后的补充消息处理，以及撤回离线要求时的同义条件残留。

## 验证与边界

- 功能验证沿用同一源码的安装、对话、整理和图标原生验收记录；发布候选额外执行完整测试、构建、签名、隐私和 DMG 校验。
- 对方“打开即提示扫描范围过大”的具体触发条件尚未复现。用户允许复现不了时保留此事实继续；本版本不承诺该个案已彻底消失。
- 另一台 Mac 或干净账户的首次安装、手动放行和核心操作尚未获得本代证据。现有安装环境及模拟环境不替代此项，准备完成后须按当前发布规则处理该缺口。
- 公开发布后必须重新下载三个附件，核对 DMG、来源清单、校验文件与冻结候选一致。
- 回退：保留 v0.2.2 及旧附件，不覆盖已有标签；若发布后出现问题，停止推荐新版并恢复旧版下载入口。程序回退与用户资料恢复分开处理，不回写旧资料覆盖新操作。
