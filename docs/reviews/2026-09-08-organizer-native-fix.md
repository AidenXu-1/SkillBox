# 文件夹原生交互完成与本机更新

## 改动

用户看过交互预览后回复“继续”，落实 v2.50 的原生拖动：统一 Skill 行和文件夹的落点，标题归类、行间精确排序、文件夹前后与末尾排序。保留三栏、来源、大小、右键操作与文件夹管理。临时折叠正在拖动的文件夹内容以便定位，松手后恢复内容显示。

滚动范围使用真实 ScrollGeometry；行高固定并从滚动偏移推导坐标，邻行的视觉让位不反过来改变命中坐标。边缘滚动随距离渐进，折叠文件夹停留约 650 ms 展开。有效松手才保存，移出列表、切换页面或丢失焦点取消；拖动期间的 Esc 使用本应用按键监听，不依赖键盘焦点落在列表里，页面离开时释放监听。取消后的鼠标结束事件不能再激活同一段拖动。

增加名称排序，搜索、非全部筛选和名称排序时暂停拖动；切回手动排序保留原排序。整理保存沿用上一切片的元数据更新，不读取或修改 Skill 原件与安装副本。
