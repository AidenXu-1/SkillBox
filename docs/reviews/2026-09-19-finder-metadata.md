# 本地 Skill 的 Finder 文件误报修复

日期：2026-09-19。

用户反馈 vibe-project-foundation 内容未变化，仅开发目录新增了三个 `.DS_Store`。只读比较确认：24 个实际内容文件一致，仅 `templates/.DS_Store`、`templates/design/.DS_Store`、`templates/docs/.DS_Store` 多出；现有窗口显示“开发内容有更新”。

## 根因与改动

LocalSkillPackageResolver 会完整复制已选择的目录，再计算整个包的校验值，因此把嵌套的 Finder 元数据也算作新版本。顶层 `.DS_Store` 还可能被当成新的待确认内容。

- 本地打包时只从临时包排除普通 `.DS_Store`；开发源不删除、不修改。
- 顶层内容选择和开发目录变化比较使用相同规则。
- `.gitignore` 等真实隐藏文件保留；默认完整校验不变，不改变安装、复制与恢复使用的既有校验值语义。
- 限定于已确认的本地来源打包问题，没有扩大为忽略所有隐藏文件或重新定义全局校验规则。
