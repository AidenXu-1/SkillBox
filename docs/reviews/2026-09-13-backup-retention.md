## 行为

- 每份 Skill 的保存版本、每个 Agent 安装位置只保留上一份成功操作备份，最多保留 7 天。新操作成功后清理被替代的备份；启动及运行期间每小时补清到期备份。
- 先将旧恢复入口标记失效，再删除备份。恢复前核对全部所需文件，备份缺失时不会先删除当前安装内容。多位置操作只要有一部分备份被替代，整次操作都不能一键恢复。
- 正在写入或恢复失败的救援文件受保护。当前 Skill、本地开发原件、正在使用的 Agent 副本和废纸篓内容不参加清理。简短操作记录继续保留。
- 本机 App 更新通过 `app/Scripts/rollback-backups.py create` 建立一套旧 App 与配套资料，完整登记后清理上一套。备份创建时间固定，重复登记不会重新计时；清理前核对登记与内容，用户改动过的备份停止自动删除。
- Codex 任务 `skillbox`（SkillBox 回退备份清理）已启用，每小时运行同一脚本的 `clean --apply`。无异常保持安静。此任务管理已登记的本机 App 回退资料；Skill 内容由 App 自身维护。关机或相应程序未运行时，下次运行补清。
