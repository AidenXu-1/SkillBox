# 白色界面与标题栏接缝修复

用户要求修复标题栏和侧栏接缝的台阶状瑕疵，主界面使用白色。已在正式本机 App 验收，版本 3.0.1 Build30；公开发行仍为 Build29，本轮没有修改公开附件或更新源。

## 原因及改动

原界面依赖系统窗口背景及半透明材质，实际窗口可复现泛粉。窗口、侧栏、主内容及标题栏固定白色，并采用应用内浅色外观，保留蓝色状态和控件，不更改系统外观设置。提示浮层同样用不透明白色。

正文顶部边线锚定实际内容边界，消除标题栏背景与侧栏背景交界处的台阶。最初隐藏标题栏背景的候选会让内部分隔线透进标题栏，最终改为可见白色标题栏遮挡层，原生窗口复核不再透出。
