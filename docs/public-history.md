# 公开历史整理说明

2026-10-21，项目整理了早期3份开发文档中出现的开发者本机路径。只替换这些路径，保留文档其余内容、所有87次原开发提交的顺序、作者、时间和说明。58个历史提交的编号因此改变，原始本地开发档案另行保留。

## 对使用和下载的影响

- 全部11个旧版本名称保留，下载入口保持。
- 每个版本标签的完整源码文件、权限及内容保持一致，可由[版本来源对应表](public-history-map.json)中的源码树摘要核对。
- 已上传的44个发行附件均保留原文件、原名称和原SHA-256。安装包、更新ZIP、完整源码ZIP、发布清单及校验文件均未重新生成。
- 默认分支中的应用代码、构建配置、资源和签名更新清单保持一致；本次仅额外增加这份说明、对应表和README入口。
- 应用版本仍为3.0.3 Build32，更新地址和签名密钥未改变，普通用户无需重新安装或调整更新设置。

历史发布清单中的提交编号记录当时的构建出处。本次整理后，使用对应表中的当前编号或原版本标签获取源码；其源码内容与当时版本完全一致。不要因为历史编号变化而重新制作或覆盖旧安装包。

## 已有开发克隆

已有克隆请先保存本地未提交工作和独立历史备份，然后重新克隆公开仓库。需要保留的代码改动先审阅成独立补丁，再移到新的公开历史上；不要合并或直接推送旧历史，以免把已移除的路径重新上传。

本机原开发仓库继续保留完整旧历史。向GitHub提交后续改动时，应以整理后的公开历史为基础，并先检查补丁及来源关系。

## 平台缓存范围

公开分支和版本标签中的历史已经整理。旧克隆、他人保存的副本和GitHub按旧编号保留的缓存属于不同范围，不能通过一次推送保证全部消失。若旧编号内容仍可访问，需要由GitHub平台进一步处理；不应将版本引用整理等同于服务器缓存彻底清除。
